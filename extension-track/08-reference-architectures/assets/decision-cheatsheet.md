# Which Pattern Should I Choose?

## If You Need Domain-Specific Task Quality

Choose: `Adapt-and-Apply`

## If You Need Evidence-Grounded Answers Over Documents

Choose: `Retrieval-Grounded Knowledge Assistant`

## If Quality Is Uncertain and Stakeholders Need Proof

Choose: `Evaluate-and-Improve Loop`

## If Workload Is Large-Scale Request/Corpus Processing

Choose: `High-Throughput Inference Factory`

## Tie-Break Rule

Pick the pattern with:

1. smallest pilot scope
2. clearest evaluation gate
3. fastest path to customer-visible outcome
