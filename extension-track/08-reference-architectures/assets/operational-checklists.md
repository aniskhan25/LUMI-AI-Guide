# Operational Checklists by Architecture

## Adapt-and-Apply

- adaptation objective documented
- dataset lineage/version captured
- evaluation gate attached to release decision
- inference packaging mode chosen

## Retrieval-Grounded Assistant

- corpus/chunk IDs stable
- retrieval index build validated
- evidence IDs included in outputs
- retrieval and groundedness metrics tracked

## Evaluate-and-Improve Loop

- benchmark set version locked
- deterministic scoring pipeline
- failure taxonomy reviewed
- controlled variant comparison completed

## High-Throughput Inference Factory

- request schema validated
- response/error join by stable IDs
- throughput/latency measured consistently
- downstream handoff contract verified
