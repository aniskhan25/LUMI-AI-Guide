# Reference Architecture Catalog

## A) Adapt-and-Apply

- Primary need: domain adaptation before repeated inference
- Strongest value: model specialization for stable task definitions
- Key checkpoint: adaptation benchmark gate

## B) Retrieval-Grounded Knowledge Assistant

- Primary need: evidence-grounded answers over changing corpora
- Strongest value: traceable responses with retrieval context
- Key checkpoint: retrieval + groundedness gate

## C) Evaluate-and-Improve Loop

- Primary need: quality uncertainty and iterative trustworthiness improvement
- Strongest value: controlled before/after decisions
- Key checkpoint: no-regression quality gate

## D) High-Throughput Inference Factory

- Primary need: large-scale corpus or request processing
- Strongest value: throughput-oriented execution with stable schemas
- Key checkpoint: completion + throughput gate
