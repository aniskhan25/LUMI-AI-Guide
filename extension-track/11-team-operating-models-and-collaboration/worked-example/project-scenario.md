# Worked Example: Project Scenario

## Scenario

A team is building an internal technical-manual assistant.

- corpus owner curates documentation snapshots
- workflow developer maintains retrieval and generation pipeline
- evaluator owns benchmark and failure analysis
- delivery owner publishes approved artifacts for application integration

## Collaboration Risk

The project is technically functional but fragile:

- multiple dataset copies are treated as authoritative
- promoted outputs are saved without explicit approver
- handoff packages vary by person

## Objective

Define a collaboration blueprint where ownership, review, sharing, and handoff are explicit and repeatable.
