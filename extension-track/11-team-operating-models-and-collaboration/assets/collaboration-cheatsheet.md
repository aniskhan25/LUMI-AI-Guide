# Collaboration Cheat Sheet

## Three Rules

1. One owner per artifact class.
2. One source-of-truth per dataset version.
3. One explicit review gate before promotion.

## Minimum Team Roles

- data custodian
- workflow developer
- evaluator
- promotion approver
- delivery owner

## Minimum Handoff Payload

- promoted artifact ID
- source run ID
- evaluation summary
- intended use and known limitations
- storage path and access scope
