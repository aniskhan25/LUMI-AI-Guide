# Handoff Checklist Template

Use this checklist before handing artifacts to another contributor or team.

## Required Package

- promoted artifact identifier
- source run identifier
- dataset and config versions
- evaluation summary
- intended use and known limitations
- retrieval path and access instructions

## Handoff Validation

| Check | Yes/No | Notes |
|---|---|---|
| Receiving team is identified |  |  |
| Artifact owner is identified |  |  |
| Review approval is attached |  |  |
| Dataset source-of-truth is documented |  |  |
| Access scope is least-privilege for receiver |  |  |
| Escalation contact exists |  |  |
