# Extension Track

Advanced topics for users who have completed the six core lessons. Each lesson has runnable scripts and job files that follow the same container workflow as the core guide.

## Model workflows

- [01. Foundation model adaptation](01-foundation-model-adaptation/README.md) — config-driven fine-tuning with JSONL datasets; builds on L6
- [02. Inference and embeddings](02-inference-and-embeddings/README.md) — batch inference and mean-pooled embeddings on MI250X
- [03. RAG and knowledge workflows](03-rag-and-knowledge-workflows/README.md) — chunk → embed → index → query pipeline
- [04. Evaluation and trustworthiness](04-evaluation-and-trustworthiness/README.md) — systematic evaluation, failure analysis, and reporting
- [05. Synthetic data and data-centric workflows](05-synthetic-data-and-data-centric-workflows/README.md) — generate and filter synthetic training data

## Scaling and serving
