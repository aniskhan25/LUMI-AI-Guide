# Naming Cheat Sheet

Use stable, sortable identifiers.

## Run IDs

- format: `run-YYYYMMDD-NNN`
- example: `run-20260312-001`

## Promoted Version IDs

- format: `version-<workflow>-YYYY-MM-DD-<suffix>`
- example: `version-rag-2026-03-12-a`

## Dataset Versions

- format: `<dataset>-v<major>.<minor>`
- example: `corpus-v3.2`

## Config Versions

- format: `<workflow>-config-v<major>.<minor>`
- example: `rag-config-v1.4`

## Rule

Never reuse identifiers for modified artifacts.
